# Learning visualizations

Open a file directly in a browser; no installation, server, CDN, or framework is needed. Each example has an English interface, light/dark themes, and a compact desktop layout targeting 1280×720. Mobile views and opened reference notes may scroll.

| Example | Explore | Scope |
| --- | --- | --- |
| [Gradient descent](gradient-descent.html) | Change the learning rate, inspect the next-step preview, then run, pause, or advance the trajectory. | Exact one-dimensional quadratic, fixed positive learning rate, no noise. |
| [Spanish word order](spanish-word-order.html) | Compare English and Spanish sentence tiles and predict the position of a color adjective. | Neutral color-adjective placement in the selected example, not a rule for every Spanish adjective. |
| [Process bottlenecks](bottleneck.html) | Change station capacities in an isometric chain and compare capacity with output in the accompanying chart. | Deterministic serial production with sufficient material, demand, and buffers. |
| [MacBook Pro](macbook-pro.html) | Exploded view of the 14-inch MacBook Pro with PROLED XDR Display: the lid's layer stack (glass, tandem OLED with built-in touch sensor, camera, lid) and the base. Export a labelled PNG or SVG. | Apple's published specs, announced 28 October 2026; proportions illustrative, items marked reported come from press coverage. |
| [Key switch](keyboard-switch.html) | Exploded view, vertical: descend from above to eye level, turn and tilt, open each of the eight parts. | Typical linear switch; dimensions and forces are typical values. |
| [Limo door](limo-door.html) | Exploded view, horizontal through the door's thickness; armour and five-ply window. | Public reporting only; layer split and thicknesses are illustrative. |
| [Flashlight](flashlight.html) | Exploded view, horizontal along the beam. | Generic two-cell AA flashlight; typical values. |
| [Studio Display XDR](studio-display-xdr.html) | Exploded view, horizontal from glass to back. | Apple specs; generic mini-LED layers marked typical. |

These are full-explanation showcases. A hint artifact would contain only the current hint, including in its source. They are not recordings of real tutoring sessions or evidence of learning effectiveness.

## Shared patterns

The examples use the [shared shell](../assets/visualization-shell.html): a consistent header, type scale, and task grouping. The capacity chart uses its comparison-row pattern; the language example uses its annotated-item pattern. The skill has these same components available for new requests.

## Request the same learning scope

After starting the skill, ask for one of these scopes. Generated copy and composition may vary.

```text
Create a full-explanation HTML exploration of
gradient descent on f(x) = (x - 3)^2 with live learning-rate feedback.
```

```text
Create a full-explanation HTML comparison of
English and Spanish color-adjective placement using sentence tiles.
```

```text
Create a full-explanation HTML exploration of
a three-stage production bottleneck, with an isometric line and capacity chart.
```

The main README includes rendered GIF previews of all three models and an illustrative learning conversation. They are authored previews, not browser recordings. Rendering sources and frames stay outside this repository.
